Версия с++17, компилятор clang++ 

Программа для вычислений в поле рациональных функций Q(x1, ..., xn) над полем рациональных коеффициентов Q. 

Программа при запуске принимает в качестве 1 аргумента название файла, из которого она будет считывать символы.

Пример запсука программы: ./translator.exe test.txt

Сам файл состоит из таких строк:

VAR1 = EXPR1;
VAR2 = EXPR2;
...
VARN = EXPRN;

Вычислительная машина последовательно обрабатывает каждую строку (каждая строка заканчивается ;): вычисляет выражение справа и присвает результат вычислений переменной (производится запись в символическую таблицу).

Лексер, парсер (LL(1)) и эмиттер написаны на С++. 

Реализованы операции сложения ("+"), вычитания ("-"), умножения ("*"), деления ("/"), возведения в степень ("^"). 

Есть поддержка унарных минусов и плюсов, числа ограничены типом long long. 

Для сокращения дробей (элементов поля рациональных функций) - поиска НОД у числителя и знаменателя - применяется нахождение полного базиса Гребнера по алгоритму Бухбергера.

Для всех операций во время вычислений добавлена проверка на переполнение. 

При переполнении во время вычисления НОД для сокращения дроби, сокращение не производится. 

Операция возведения в степень всегда предполагает наличие целого делителя (без переменных х).

Поддерживаемые грамматики (для неявного умножения): 5(x1+1), x1(x2+1), (x1+2)x2

Недопустимые грамматики (для неявного умножения): (x+1)5, x1 x2, 5 5

Программа сначала показывает результат синтаксического разбора для каждой строки - имя переменной, знак присваивания и очередь операторов и операндов (при успешном разборе), а затем выводит все вычисленые переменные из символьной таблицы и их значение.

Переменные в мономах и мономы в полиномах отсторированы в лексикографическом порядке.
